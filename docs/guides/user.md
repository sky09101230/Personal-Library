# AgentSys 使用者说明书

本文面向科研成员和管理员。系统只展示已登录用户有权访问的内容；普通成员不能访问管理员工具。页面名称以当前中文界面为准。

## 1. 登录和账户

访问站点后：

1. 已有账号选择“登录”，输入用户名和密码。
2. 没有账号选择“注册”，填写用户名、可选邮箱、密码和管理员提供的一次性邀请码。
3. 注册成功后会自动登录。邀请码只能使用一次，失效、过期或已消费的邀请码不能重复使用。
4. 使用“退出”结束当前会话。不要在公共电脑保存密码或 MCP 令牌。

登录后首页提供“文献库”“上传 PDF”“我的上传”“Skills”等入口；管理员还会看到 Zotero、metadata 审核、候选审核、GitHub 搜索、学术推荐和 Django Admin 入口。

## 2. 文献库

### 搜索、筛选和查看

进入“文献库”后可以：

- 在搜索框按文件名、标题、期刊或 DOI 搜索。
- 按期刊、发表年份和关联用户筛选；使用“待处理”查看 metadata 尚未验证的记录，使用“未发布”查看不在 Agent 上下文的例外记录。
- 点击文献标题或“在线打开”在浏览器中查看 PDF；点击“下载”保存 PDF。大文件按流式方式读取，下载链接可能在数分钟后过期，过期后重新进入页面获取。
- 查看标题、作者、摘要、期刊、年份、DOI、metadata 状态、发布状态、上传者和附件角色。正文 PDF 优先于补充材料。

“Agent 可检索”只统计 `published` 文献。metadata 仍待复核并不代表文件丢失；但没有成功保存正文 PDF 的 Zotero-only 记录不会进入 MCP 文献列表。

### 我的上传和删除

“我的上传”包含你实际上传的 PDF，也包含通过 DOI 或 Zotero 关联到你的文献。你可以审核自己关联文献的 AI 建议，但只能删除自己实际提交的附件：

1. 在附件操作中点击“删除”。
2. 确认后系统先从 NAS 删除文件，再删除数据库记录。
3. 如果 NAS 删除失败，页面会保留记录并提示失败；不要反复刷新或手工改数据库，联系管理员处理。

删除别人上传的附件、批量清理对象存储和 orphan 文献需要管理员权限。

## 3. 上传 PDF：暂存、核对、确认

网页上传现在是两阶段流程，避免错误 metadata 直接进入正式文献表。

1. 打开“上传 PDF”，选择一个或多个 `.pdf` 文件。系统会校验 PDF 签名、大小、摘要并将文件暂存到 NAS。
2. 等待每个文件的进度状态。失败文件不会自动换成其他来源；记下错误文件名和阶段。
3. 在暂存审核表中检查标题、作者、DOI、期刊、年份和来源证据。
4. 标题缺失时必须先编辑标题。期刊缺失是黄色提醒，预印本、数据集或会议论文可以在确认时保留为空。
5. DOI 不正确或识别到了参考文献 DOI 时，在对应文件中输入正确 DOI，点击重新解析；成功后 BibTeX 预览会替换相关 metadata。
6. 需要一次性确认时点击“确认并入库”。确认在一个事务中完成，正文 PDF 才会创建正式文献记录并发布；重复 DOI/SHA-256 会关联已有文献而不会重复保存。
7. 放弃整个批次时点击“取消本批上传”。系统会清理暂存 NAS 文件；如果清理失败，批次会保留待管理员处理。

确认前暂存内容只对上传者可见，不进入文献库、MCP 或管理员 metadata 队列。确认后可以继续修正 metadata，但不要通过重新上传相同 PDF 来“刷新” metadata。

## 4. AI metadata 审核

上传后系统可能生成 DeepSeek metadata 建议。管理员和该文献的上传者可以在“文献库”的“待我确认”入口查看：

1. 打开审核队列，按 pending、已接受、已拒绝、失败等状态筛选。
2. 点击一条记录查看原始 metadata、AI 建议、证据和警告。
3. 对安全且完整的建议点击“接受”；也可以先修改标题、作者、摘要、期刊、年份、DOI 和标签后保存。
4. 有 DOI/标题冲突、作者为空、年份异常或来源证据不足时，不要批量接受，使用详情页人工核对。
5. 失败、拒绝或过期的建议可点击“重新生成”。DeepSeek 未配置时不会向外部 API 发送文献内容。

接受 metadata 不会自动改变文献发布状态；发布边界由正文 PDF 是否成功入库和 `index_status` 决定。管理员可以在文献操作中编辑 metadata 或处理下架等例外。

## 5. 从 Zotero 导入（管理员）

该功能当前仅管理员开放，普通成员看到“正在测试升级当中”。管理员按以下步骤操作：

1. 打开“从 Zotero 导入”，选择“个人文献库”或“群组文献库”，填写 Library ID 和 Zotero API Key，点击连接。
2. 首次连接成功后，API Key 会加密保存，页面不会再次显示明文；以后可以留空 API Key 复用已保存连接。
3. 选择 Collection，勾选要导入的顶层文献。每条文献可选取当前电脑上的本地 PDF。
4. 点击“导入选中条目”并观察进度。PDF 来源顺序是：当前浏览器选择的 PDF → 服务器上的 Zotero Desktop → Zotero Web。
5. 仅导入明确选择或 Zotero 中 `imported_file + application/pdf` 的托管 PDF；网页快照、URL 附件、linked file 和非 PDF 会跳过。
6. 单条 PDF 失败不会撤销其他条目；metadata 仍会保留，稍后可以在文献库继续处理。导入完成后打开文献库检查发布状态和重复关联。

## 6. Skills 广场

### 查找和下载

进入“Skills 广场”：

- 用名称、描述或 slug 搜索 Skill。
- 先选大用途，再选小用途；“未分类”表示尚未完成自动分类或没有合适的现有用途。
- “管理员精选”查看经过管理员实际使用后的推荐。
- 打开详情查看来源、路径、提交版本、描述和发布包，点击“下载 ZIP”获取当前发布版本。下载包来自正式发布快照，不是未经审核的 GitHub HEAD。

### 投稿一个 Skill

任何已登录成员都可以投稿：

1. 进入“投稿 Skill”，上传只包含一个 Skill 的 ZIP。
2. 等待系统检查压缩包结构、`SKILL.md`、路径安全、大小、禁止资产和内容摘要。
3. 在“我的投稿”查看 pending、已发布或已拒绝状态及提示/拒绝原因。
4. 候选在管理员批准前不会出现在正式 Skills 广场、下载接口或 MCP 上下文。不要把论文、实验数据、数据库、向量索引、模型权重、私钥、`.env` 或访问令牌放入 ZIP。

### 管理员审核与发布

管理员在“候选审核”中：

1. 按来源和状态筛选候选，打开详情查看来源、提交者、校验错误/提醒、摘要和建议分类。
2. 修正展示摘要（最多 400 字符）和科研任务分类；人工分类会受到后续 AI enrichment 保护。
3. 对通过校验且内容合适的候选点击“批准并发布”，或批量选择后发布。
4. 需要拒绝时填写明确原因。发布会复制审核时的候选快照到 NAS，并创建正式 Skill 和 Release；扫描结果本身不会直接发布。

管理员还可以：

- 在“Skills 广场”选择已启用 GitHub 来源，点击“扫描到候选池”；任务完成后到候选审核逐个审核。
- 在“搜索 GitHub Skill”按至少 2 个字符搜索公开 `SKILL.md`，先检查许可证，再加入候选池。GitHub 仓库变化或许可证缺失时导入会停止。
- 点击“重新生成正式 Skill 摘要”运行独立的 DeepSeek 摘要/分类任务；人工描述和人工分类不会被覆盖。
- 在“学术推荐”刷新有限关键词范围内的 GitHub 学术 Skill 推荐。推荐只是候选发现，不会自动创建正式 Skill；需要点击“检查许可证并加入候选池”后再走正常审核。
- 在 Django Admin 的 `Skill purposes` 维护大用途/小用途，在 `Featured skills` 维护精选推荐和排序，在 `GitHub skill sources` 启用或停用来源。

## 7. Django Admin 管理员功能

访问 `/admin/` 后，管理员可以维护用户、邀请码、文献、外部 Zotero 引用、metadata 提案、Skill 来源/分类/正式记录/候选/发布包、后台任务和 MCP 访问令牌。

- 生成邀请码：创建后只在结果页显示一次，使用后自动失效。
- 创建 MCP 令牌：选择 owner、label、scope 和过期时间。明文令牌只显示一次；重新生成会立即使旧令牌失效。令牌至少只授予需要的 scope。
- 删除 PDF：在 `Uploaded documents` 使用专用删除动作并确认。系统先删 NAS，再删数据库；存储失败时保留记录。不要使用 Django 默认的无确认批量删除。
- 处理 Zotero 外部引用时，删除孤立引用可能同时删除没有 PDF 的孤立规范文献；先确认没有其他附件或引用。

## 8. 通过 MCP 使用资料库

需要管理员签发 Token，并由管理员提供 MCP 服务地址。将令牌放到本机环境变量（例如 `PLAB_MCP_TOKEN`），不要写入聊天、代码或仓库。Codex 配置示例：

```toml
[mcp_servers.plab_library]
url = "https://<站点域名>/mcp"
bearer_token_env_var = "PLAB_MCP_TOKEN"
```

重启 Codex 后可调用：

| 工具 | 需要 scope | 用途 |
| --- | --- | --- |
| `list_literature` | `literature:read` | 按文件名、标题、DOI、期刊或 SHA-256 检索已发布文献，支持分页 |
| `get_literature` | `literature:read` | 按文献 ID 查看 metadata |
| `get_literature_download_link` | `literature:read` | 获取已发布正文 PDF 的短时下载链接 |
| `upload_literature` | `literature:write` | 上传 Base64 PDF；服务端仍执行大小、PDF、DOI、重复和 NAS 校验 |
| `list_skills` | `skills:read` | 按名称、描述或用途标签检索正式 Skill |
| `get_skill` | `skills:read` | 按 Skill ID 查看详情 |
| `get_skill_download_link` | `skills:read` | 获取当前正式发布包的短时下载链接 |

MCP 只返回 `published` 文献和正式 Skill；候选、暂存上传、pending metadata 和未发布内容不会进入 Agent 上下文。常见错误：401 表示 Token 缺失/无效/过期/停用，403 或工具错误通常表示 scope 不足；下载链接过期时重新调用下载工具即可。

## 9. 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 上传后找不到文件 | 查看上传结果中的文件名和失败阶段；检查是否只暂存未确认，或确认时标题仍为空 |
| 同一论文显示一次 | DOI 或 SHA-256 去重是预期行为；新上传者会关联到已有文献，不重复保存 PDF |
| DOI 识别错误 | 在暂存审核表输入正确 DOI并重新解析，核对标题后再确认 |
| AI 建议失败 | 保留原始 PDF 和 metadata，稍后重新生成；不要因为 AI 失败而重复上传 |
| Skill 投稿未出现在广场 | 候选必须经过管理员审核和发布；pending 是正常状态 |
| Zotero 没有 PDF | 检查是否选择了浏览器本地 PDF，或该附件是否为托管 imported PDF；URL/linked file 不会自动上传 |
| 下载返回 401/404 | 重新登录或重新获取短时链接；文献必须已发布且存在正文 PDF |
| 页面提示存储失败 | 联系管理员检查 NAS 地址、服务账号、根目录权限和证书；不要手工删除数据库记录 |
