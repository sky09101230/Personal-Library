# 0015 上传前预检 DOI BibTeX

## 决策

对于需要新建规范文献记录且能从 PDF 提取到 DOI 的上传，系统必须在向 NAS 写入批次内任何文件之前完成真实 DOI BibTeX 请求并验证响应。任一预检失败时整批停止，不产生 NAS 文件或上传数据库记录；预检结果在后续 metadata 解析中复用。

无 DOI 的 PDF 和已有内容的重复上传不执行该预检。Crossref 仍是上传后的补充来源，其失败不阻断上传。

本决策替代 `0012-doi-bibtex-primary-metadata.md` 中“DOI resolver 不可用时仍保留上传并回退 Crossref”的上传时失败策略；该 ADR 的来源优先级、证据和冲突处理规则保持不变。

## 理由

额外 ping 只能证明某个时刻的主机可达，不能证明实际 DOI 内容协商会成功。前移并复用真实 BibTeX 请求，可以在产生存储副作用前验证网络、HTTP 响应和 BibTeX 格式，同时避免重复请求。

## 约束

- 批次预检必须先于任何 NAS 写入。
- 预检失败必须以可重试的浏览器弹窗提示。
- 不新增健康检查端点、依赖或数据库迁移。
- Crossref 可用性不属于本预检范围。
