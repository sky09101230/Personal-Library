# 0023 DOI 文献身份与上传者关联

## 决策

有 DOI 的文献以规范化 DOI 作为唯一身份，数据库以不区分大小写的唯一约束阻止重复规范文献。`CanonicalDocument` 独立记录上传者；PDF 附件仍由 `UploadedDocument` 表示。

上传 PDF 或导入 Zotero 附件时，如果相同 DOI 已有 PDF：

- 当前用户尚未关联时，只加入上传者，不再保存 PDF 或创建附件记录。
- 当前用户已经关联时，提示重复并跳过，不产生任何存储或数据库副作用。

相同 DOI 只有 metadata、尚无 PDF 时，首个 PDF 仍正常写入。无 DOI 文献继续使用 SHA-256 复用现有规范文献。

## 数据迁移与清理

迁移从现有附件回填上传者关联。上线唯一约束前，必须先处理历史重复 DOI：保留 metadata 与可用附件最完整的一篇；同一上传者的重复 PDF 从存储和数据库删除，不同上传者只合并上传者关联。

## 约束

- DOI 在比较和保存前使用现有 `normalize_doi`。
- 重复判断必须发生在 NAS 写入前；并发竞争由数据库唯一约束兜底。
- 删除附件时先删除存储对象；存储删除失败则保留数据库记录。
- “我的上传”和上传者筛选使用文献上传者关联，附件删除权限仍只属于附件原上传者。
