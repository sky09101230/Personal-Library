# 0005 后台同步与进度轮询

## 决策

Skills 同步由独立 Django management command 在后台进程执行，任务状态和计数写入 `SkillSyncJob`，Skills 页面通过状态接口轮询显示当前来源、当前 Skill、上传数和跳过数。

## 理由

GitHub clone 和 NJU Box 上传都可能持续数分钟。同步不能占住浏览器请求，也不能只在最终完成后才反馈结果；数据库任务记录还能在页面刷新后恢复进度。

## 约束

- 同一时间只启动一个排队中或运行中的同步任务。
- 每个 ZIP 上传成功或判定已存在后立即更新任务计数。
- 单个来源失败会记录错误并继续尝试其他来源；全部来源失败时任务状态为失败。
