# ADR 0032：GitHub Skill 排序、摘要与学术推荐

- 状态：已接受
- 日期：2026-08-13

## 决策

GitHub 代码搜索不能按 Star 排序，也不保证返回完整仓库信息。系统只对每次搜索返回的当前页补查仓库详情，显示 Star 和最近代码更新时间，并在本页内从高到低排列；页面不得把它称为 GitHub 全量排行。

搜索预览保留 `SKILL.md` 的不可变 blob SHA。当前页未缓存的文档由服务端限量读取并合并为一次 DeepSeek 请求，生成两句中文摘要和学术适用性判断。摘要按文件版本、模型、服务地址和提示词版本缓存 7 天；任何 AI 失败都不影响查看或导入 GitHub 结果。

学术推荐只向管理员开放，由管理员手动启动后台刷新。系统从固定、非空且有限的学术关键词结果中选择少量高 Star 候选，再使用相同的 DeepSeek 文档评估生成推荐理由。推荐记录仓库、代表文件、Star、最近代码更新时间、文件版本、模型、提示词版本和评估时间。

## 数据与发布边界

普通搜索结果和摘要不进入数据库。学术推荐保存在独立快照表中，不复用正式 `FeaturedSkill`、扫描来源或候选模型；整轮刷新成功后才原子替换，失败保留旧快照。

查看或刷新推荐不会创建来源、候选、正式 Skill 或 NAS 文件。管理员点击导入后，服务器仍重新检查仓库、文件、提交和许可证，并只把内容送入私有候选池；人工审核发布仍是进入 Skills 广场和 MCP 的唯一入口。

## 取舍

第一版不抓取全部 GitHub 命中、不做定时刷新、不增加 GitHub SDK、队列系统或新的缓存服务。推荐只代表固定关键词有限候选池在最近一次评估时的结果，页面必须明确显示这一限制与评估时间。
