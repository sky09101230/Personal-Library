# 0034 PDF metadata 身份防护与补充材料识别停用

## 决策

PDF 同时包含多个同名 DOI 候选时，标题匹配相同的情况下优先选择带期刊或会议出版容器的记录，避免把关联研究数据集 DOI 当成论文 DOI。

`untitled` 等已知 PDF 生成占位标题不作为 metadata 证据。系统先将其视为空，再尝试从首页提取标题；提取失败时保持为空，不触发标题冲突。

网页上传暂时停止根据关键词自动判断补充材料，所有新上传 PDF 按正文处理。历史 `supplementary` 记录、展示及正文优先下载保持不变。本决策暂停 0033 中的自动识别部分，但不撤销其文件角色模型。

## 理由

论文与数据集可以使用相同标题，PDF 内嵌标题也经常是生成工具占位符，二者都不能单独证明文献身份。当前补充材料关键词规则还会把正文中的说明误当成文件角色；在新的可靠识别或人工指定方案形成前，停用自动分类比继续产生错误归属更安全。
