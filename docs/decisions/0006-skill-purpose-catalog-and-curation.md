# 0006 用途分类与管理员精选

## 决策

Skills 广场按管理员维护的两级用途分类浏览：大用途对应页面一级标签，小用途对应二级标签。GitHub 来源继续只用于同步和溯源，不参与前台分区。管理员精选使用单独的 `FeaturedSkill` 记录保存被选中的 Skill、一句推荐语和排序，并在独立页面展示。

## 理由

仓库来源只说明代码在哪里，不说明用户何时应使用该 Skill。用途标签更贴近科研工作流；管理员精选则让经过实际验证的工具得到独立入口，不依赖自动排序或生成式推荐。

## 约束

- 分类完全由管理员配置，不自动推断；未配置的 Skill 保留在未分类标签。
- 每个 Skill 只能归属一个小用途，以保证浏览路径明确。
- 每个 Skill 最多有一条精选记录，并由管理员填写不超过 240 字的一句推荐语。
