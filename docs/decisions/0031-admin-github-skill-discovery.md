# ADR 0031：管理员搜索并单项导入 GitHub Skill

- 状态：已接受
- 日期：2026-08-13

## 决策

GitHub Skill 发现入口只向管理员开放。管理员必须输入 2 至 80 个字符的关键词，系统固定通过 GitHub 代码搜索查找 `SKILL.md`，每页 20 条，并缓存相同查询 3 分钟；不提供空关键词的“搜索全部”。

GitHub 令牌只从服务器环境变量 `GITHUB_API_TOKEN` 读取，不进入页面、数据库或日志。令牌只允许访问公开资源，不授予私有仓库或写入权限。

管理员每次只能选择一个结果。服务器会重新确认公开仓库、默认分支提交、目标文件和 GitHub 可识别许可证；许可证不明确时只能查看 GitHub 页面，不能复制进候选池。通过检查后，系统自动创建或复用来源，只扫描所选目录，并把仓库许可证文件保存在候选快照中。

## 发布边界

搜索导入只创建私有 `SkillCandidate`，不会创建正式 Skill 或发布记录。候选仍需经过现有内容校验、摘要分类和管理员审核，批准后才会进入 Skills 广场和 MCP。仓库在检查与克隆之间发生变化时，本次导入停止，管理员需要重新搜索。

## 取舍

GitHub 代码索引可能延迟或遗漏结果，因此保留原有固定来源整仓扫描作为补充。第一版不做批量导入、实时联想、自建索引、搜索结果持久化或自动发布。
