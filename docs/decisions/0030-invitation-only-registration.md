# ADR 0030：注册使用一次性邀请码

- 状态：已接受
- 日期：2026-08-12

## 决策

新账号注册必须提交管理员生成的邀请码。每个邀请码只能成功注册一个账号，自生成起 30 天后失效，并可由管理员提前停用；已有账号不受影响。

邀请码使用安全随机数生成，明文只在后台生成结果页展示一次，数据库只保存 SHA-256 摘要。账号创建与邀请码消费放在同一数据库事务中，避免表单失败提前占用，也避免同一码并发创建多个账号。

## 结果

- 能访问注册页不再等于可以创建账号。
- 管理员需要通过 Django 后台生成并单独发送邀请码。
- 离开生成结果页后无法找回明文，需要时重新生成。
- 本决策暂不加入邮箱验证、验证码或注册审批流程。
