# ADR-0001：采用单一私有 Monorepo

- 状态：已接受
- 日期：2026-08-04

## 背景

PLAB Scientific Agent 第一阶段需要共同交付 Web 应用、后台任务、文献解析、检索、Agent 和部署配置。这些部分共享数据模型并需要同步发布。

## 决策

当前只维护一个私有仓库 `PLAB-Scientific-Agent`，其中包含平台代码、文档、测试和部署配置。

不为前端、后端、AI、数据库或部署分别建立仓库。科研文件、数据库数据和检索索引不进入 GitHub。

## 后果

- 一次 Pull Request 可以原子更新数据模型、代码、测试和部署配置。
- 权限、CI 和版本管理保持简单。
- 阶段三只有在 Skill 具有独立贡献权限和发布周期时，才重新评估 `PLAB-Skills` 仓库。
