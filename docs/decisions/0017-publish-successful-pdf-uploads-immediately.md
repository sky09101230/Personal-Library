# 0017 成功上传的 PDF 立即发布

## 决策

PDF 对象存储和数据库登记均成功时，`CanonicalDocument.index_status` 立即设为 `published`。新文献和精确重复上传使用同一规则；管理员仍可在异常情况下手动下架或调整状态。

部署时，现有 11 篇带已上传 PDF 的 pending 文献已一次性切换为 published；没有 PDF 的外部引用不在此操作范围内。

## 理由

上传成功已经证明 PDF 可读取且记录已持久化，继续要求管理员逐条发布只增加等待步骤。发布状态写入现有数据库事务，可保证数据库失败时不会留下由该失败操作产生的已发布记录。

## 边界

- 仅上传 PDF 触发自动发布；Zotero-only 记录不自动发布。
- DOI/BibTeX 预检仍发生在对象存储写入之前。
- 元数据复核与发布解耦，上传后可继续改进元数据。
