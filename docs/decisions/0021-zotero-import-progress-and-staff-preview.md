# 0021 Zotero 导入进度与管理员预览

## 决策

Zotero 导入使用同一 HTTP 请求内的 NDJSON 流返回“进度百分比 + 当前动作”，复用现有进度条样式，不增加任务表、轮询服务或运行依赖。视图在读取表单前检查 `is_staff`；普通成员只看到“正在测试升级当中”，直接 POST 返回 403。

## 理由

导入本身已经是顺序分页和逐条落库，直接暴露这些真实阶段即可满足可观察性，同时保持 API Key 仅存在于当前请求。后台任务只有在需要断线续传或跨进程恢复时才值得增加。

## 边界

本次只覆盖 Zotero 导入。反向代理需要尊重 `X-Accel-Buffering: no` 才能实时刷新；其他长任务应先确认真实阶段和权限边界，再复用该交互。
