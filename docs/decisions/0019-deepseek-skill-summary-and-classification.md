# 0019 DeepSeek Skill 摘要与自动分类

## 决策

摘要与分类使用独立后台流程：该流程只克隆所选 GitHub 仓库、让 DeepSeek 阅读对应 `SKILL.md`、生成恰好两句话的中文摘要并选择一个现有叶子用途，随后只更新数据库。它不初始化、读取或写入 Skill 文件存储。GitHub 发布包同步不调用 DeepSeek。顶层用途在没有子用途时也视为叶子用途并可直接承载 Skill。该决策取代 0006 中“分类完全由管理员配置”的约束。

## 理由

仓库 front matter 的英文 `description` 面向 Agent 触发，不适合作为 Skills 广场的用户说明；分类也不应成为每次同步后的固定人工步骤。摘要生成与 ZIP 发布没有存储依赖，因此不应为更新展示文案而访问 NAS/NJU Box。

## 约束

- 摘要只能依据 `SKILL.md`，必须是两句中文完整句子。
- 分类只能选择数据库中已存在的叶子用途；没有合适用途时保留未分类。
- 已有人工分类不会被自动结果覆盖，管理员仍可纠错。
- 使用提交哈希、模型和提示词版本记录摘要来源；同一提交不重复调用 DeepSeek。
- DeepSeek 未配置或返回无效结果时，本次摘要与分类任务失败，不影响发布包同步，也不降级为原始英文描述。
