# 0020 管理员覆盖 Skill 展示描述

## 决策

管理员可从 Skill 卡片或详情页进入专用表单，在 DeepSeek 原始摘要基础上修改展示描述。系统分别保存最近一次 `ai_generated_description` 与对外展示的 `description`；管理员保存后标记 `description_is_manual`，后续 GitHub 同步和 DeepSeek 重生成均不得覆盖人工版本。

## 理由

生成摘要适合作为初稿，但面向科研用户的措辞需要人工校正。若只修改同一字段且不记录来源，下一次自动任务会覆盖人工判断，也无法追溯模型原稿。

## 约束

- 编辑入口仅对 staff 用户开放。
- 人工描述最多 400 个字符，不修改仓库中的 `SKILL.md`。
- DeepSeek 重生成仍更新原始摘要及模型、提交和提示词版本，但人工展示版本保持不变。
- 管理员通过 Django Admin 修改描述时采用相同的人工保护规则。
