# 0018 选择性同步 GitHub Skill 来源

## 决策

Skills 页面允许管理员在同步前选择一个已启用的 GitHub 仓库，也保留“全部已启用仓库”选项。页面提交来源 ID，后台同步命令仅处理该来源；未提交来源 ID 时继续执行原有全量同步。

## 理由

仓库配置数量增加后，全量 clone 和上传会造成不必要的等待。来源 ID 已由现有 `GitHubSkillSource` 管理，无需增加新的配置模型或依赖。

## 约束

- 只能选择当前已启用且存在的来源。
- 同一时间仍只运行一个同步任务；已有任务运行时，新请求不会改变其同步范围。
- 直接调用后台命令且未指定来源时，保持全量同步兼容性。
