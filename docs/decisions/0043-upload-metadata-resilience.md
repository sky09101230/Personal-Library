# 本机批量上传的事务与元数据回退

四通道上传在 SQLite 默认 DEFERRED 事务内先读后写，可能立即发生锁升级失败。改用 SQLite IMMEDIATE 事务并设置有限等待，事务内只保留数据库操作；不降低上传并发，不将网络请求放入写事务。

上传审核原流程仅依赖 doi.org 的 BibTeX 内容协商。该服务失败时使用 Crossref 的公开 BibTeX transform 接口，校验返回 DOI 与请求一致；保留原有多候选标题比较流程。第一页 DOI 的标题高度匹配且有期刊时直接采用，减少参考文献查询；其余候选仍并发比较。单请求超时默认从 5 秒调整为 15 秒，以适应实际网络延迟。

机构封面中可核实的作者与出版信息可以作为本地回退。无法匹配正文标题的候选 DOI 不显示为本文 DOI。所有修复只写入待审核区，正式发布仍需用户确认。
