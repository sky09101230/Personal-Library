# 0033 批量正文与补充材料上传

## 决策

网页一次上传多个 PDF 时，系统在写入 NAS 前识别正文和补充材料。补充材料只在其规范化 DOI 唯一匹配到库内或同批次中已有正文 PDF 时保存；否则直接拒绝，不创建对象、上传记录或独立文献。

上传记录使用 `primary` 与 `supplementary` 角色。正文 PDF 才能发布文献和作为默认下载对象；补充材料始终通过既有的规范文献外键附属到正文，不单独发布。

## 理由

不持久化未匹配附件可避免待关联队列、权限、可见性和清理路径。PDF 中的 DOI 是唯一可自动接受的归属证据；相似题名、OCR、外部检索和 ZIP 处理均不在本次范围内。
