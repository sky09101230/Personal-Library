# ADR-0021: 废弃 NJU Box 对象存储

## 状态

已采纳，2026-08-16。

## 决策

NJU Box 服务和数据库已停止。文献与 Skill 发布包统一使用 NAS WebDAV；应用不再保留可工作的 NJU Box 上传、读取、删除或迁移接口。

为避免误配置重新启用旧服务，`nju_box` 配置值和历史数据库值会被明确拒绝，遗留 Python 导入路径仅返回“已废弃”错误且不建立网络连接。已应用的数据库迁移、历史 ADR 与 OpenSpec 归档保留，作为部署与审计历史。

## 后果

- `.env` 和 `.env.example` 不再包含 NJU Box 凭据或目标路径。
- 新建文献和 Skill 发布记录默认且仅可选择 NAS WebDAV。
- 若发现遗留 `nju_box` 数据，必须从可验证的原始文件重新上传至 NAS，不能通过旧服务读取或迁移。
